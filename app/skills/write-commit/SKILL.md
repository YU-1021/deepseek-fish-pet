# 写 Git Commit 信息

## 步骤

1. 先看这次到底改了什么：`git status`、`git diff --stat`，必要时 `git diff`
2. 归纳这次改动的**意图**——是修了什么 bug、加了什么功能、还是只是重构。**不要罗列文件**
3. 用中文写标题，一句话说清"做了什么"，不超过 50 字
4. 改动大的话，标题下面空一行，再写 2~4 条要点（一条一个方面）
5. 不写"修改了 xxx 文件"这种废话

## 风格

- 标题用动词开头：新增 / 修复 / 调整 / 优化 / 移除 / 重写
- 一次说清，拒绝「更新代码」「优化一下」这种空话
- 技术名词保留原文（whisper、Electron、IPC…），不要强行翻译

## 例子

```
feat: 语音识别改成本地 whisper，不再依赖在线服务

- 新增 src/asr.js：本地推理，离线也能用
- 删掉旧的 Web Speech 调用
- 首次使用时自动下载模型（约 75MB）
```
