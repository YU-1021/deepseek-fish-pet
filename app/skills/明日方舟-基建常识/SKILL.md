## 一、基本概念

| 词 | 意思 |
|---|---|
| **干员** | 你要安排去上班的角色（有名字、职业、星级、技能） |
| **进驻** | 把一个干员安排到某个设施的某个位置上 |
| **撤下** | 把干员从设施里拿下来 |
| **排班 / 换班** | 按计划把谁放哪个设施、什么时候换人 |
| **心情** | 干员进驻后会持续下降；降到 0 会**停工**（设施效率掉） |
| **心情消耗** | 干员在设施里每小时掉多少心情（越费心情的岗位越需要轮换） |
| **宿舍** | 让干员恢复心情的地方（不生产，但决定你能不能一直轮班） |
| **预设队列** | 一套预先存好的进驻方案；界面上常见「队列1 / 队列2 / 队列3」 |
| **工作中** | 界面上的状态字，表示这个位置上的干员正在上班（**它是状态，不是按钮**） |

## 三、加成怎么算（这部分最容易搞错）

- 每个设施标着自己的**加成类型**（比如制造站上的「贵金属」「作战记录」）。
- 干员的**技能**决定他能给哪类加成、给多少。
- 所以"该放谁"取决于**那个设施要什么加成** —— 而不是随便塞人。
- ⚠️ **具体哪位干员对哪类加成有加成，必须查数据**（见 `干员图鉴` 技能里的 `干员总表.md`），
  **不要凭名字或职业猜**。实在查不到就如实说"我不确定这个人适不适合这里"。

## 四、换人的正规流程（已验证 ✓ —— 来自主人 40 帧实机演示）

1. 进基建 → 点左上角「**进驻总览**」，或**直接点地图上的某个设施** → 打开它的进驻详情。
2. 点设施里的**空位 / 槽位**（带「+」的那个格子）→ 弹出「**干员选择面板**」。
3. 在面板里挑人：
   - 右侧有一竖排**职业筛选图标** —— 先按职业缩小范围；
   - 干员多、一屏装不下 → 用**滚动条**或拖动列表翻页；
   - 点干员头像**选中**（可以多选，选中的头像上会出现数字标记「1」「2」）；
   - 点「**清空选择**」可以清掉重来。
4. 点右下角「**确认**」 → 人就进去了。
5. **验证**：回到那个设施，把进驻的人读出来，确认就是你刚选的那几个。
   **只点了确认、没回读验证，不算完成。**

⚠️ 界面上**没有**「角色」「换人」「换班」这几个按钮名 —— **不要去找它们**（实测为此浪费了几十步）。

## 五、常识问答（她可能被问到的）

- **"队列轮换"是干什么的？** 它跟"预设队列"有关，用于切换队列方案。
  ⚠️ **它是否会立刻改变谁在上班，我没有验证过**（未验证）—— 实测有一次点了它、队列没变，
  所以**不要假设它能换人**；要换人就走上面第四节。
- **为什么设施显示"停工/已停工"？** 通常是因为进驻的干员**心情耗尽**，或者**没人在岗**。
  这时应该换人或者安排宿舍恢复。
- **电力不够会怎样？** 一些设施会降效（未验证具体规则）。
