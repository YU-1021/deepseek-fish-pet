# 进关卡

从主界面走到目标关卡的「开始行动」按钮前。**到开始行动就停下来确认，不要自己点进去。**

## 步骤

1. 先加载 `看游戏界面` 确认当前在哪一屏；不在主界面就用 `game_find` 找左上角返回箭头（或让主人切），点回主界面。
2. `game_find "终端"` 找到底部终端按钮，`game_click` 点它（先 dry-run 看坐标，没问题再 real:true）。
3. 在关卡列表里找到目标：
   - 主线：按章节号翻（例如 16-16）；
   - 活动：切到活动页签；
   - 资源本：选对应资源（龙门币/作战记录/芯片/基建材料）。
   - 看不清就 `game_look` 重新看，或 `game_find` 搜关卡名，别乱点。
4. 点进关卡，读一下右上角的理智消耗；**报给主人并等他同意**再点「开始行动」。
5. 主人同意后 `game_click` 点「开始行动」（real:true）→ 进入编队/作战准备页 → 交给 `布阵与技能`。

## 红线

- 体力（理智）不足、要吃源石/理智药恢复时，一定先问。
- 「开始行动」这一步本身就消耗理智，属于花资源，必须拿到明确同意。
- 高难关卡不熟悉配置时，先跟主人对一下打法再动手。
