# 挂机刷图

循环刷同一关。**开始前必须拿到主人的明确同意（这会持续消耗理智）。**

## 开始前确认

1. 刷哪一关、刷多少次（或「到体力用完」「打到 XX 材料够」）。
2. 用哪套编队/打法（没指定就用上次成功的）。
3. 出错（失败/理智不足/弹窗）时：停下等主人，还是自动重试一次后停？默认**停下等主人**。

## 循环流程

1. `进关卡` 找到关卡 → 确认理智 → 开始行动。
2. `布阵与技能` 打完这一局（尽量用自动战斗/托管，别手动点满全程）。
3. 结算页点「再来一次」继续；没有「再来一次」就返回终端重新进关。
4. 每局结束报一次「第 N 局：成功/失败，剩多少理智」。
5. 达到次数或体力用完 → 停，报总结（成功 N 局、失败 M 局、掉了什么材料）。

## 异常处理

- **行动失败**：停，报「哪一局失败、场上什么情况」，问主人换打法还是继续。
- **理智不足 / 要吃理智药**：停，问主人。
- 弹窗不认识、网络错误、卡在加载：截图报给主人，最多自动点一次「重试」，不行就停。
- 连续两局失败：停，不要继续烧理智。

## 红线

- 不自己吃源石/理智药，不自己抽卡，不自己买体力。
- 不在主人没同意的情况下开新一轮挂机。
