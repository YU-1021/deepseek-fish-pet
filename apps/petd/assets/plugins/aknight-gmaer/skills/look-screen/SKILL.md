# 看游戏界面

用来看清楚游戏现在是什么状态。**这个技能不点击**，只负责读屏。

## 步骤

1. `game_look` 看当前画面（MAA 抓帧 + 识别）：返回 1280×720 画面上的文字、行数、截图路径。
2. 如果画面里是浏览器/桌面内容、完全没有游戏 UI，说明游戏被挡住了：
   - `cua_windows` 找到标题「明日方舟」/进程 `Arknights` 的窗口；
   - `cua_focus` 切到游戏窗口；
   - 再 `game_look` 一次。
3. 看不见的小字/图标可以再 `game_look` 时带 `find: ["关键词"]` 让识别顺便找（也可以单独 `game_find`）。
4. 按下面的特征判断在哪个界面，再去加载对应技能：

| 界面 | 特征 |
| --- | --- |
| 主界面 | 底部一排功能按钮（终端/干员/采购/档案…），右上角有理智 |
| 终端 | 关卡列表，分主线/活动/资源，右侧有「作战」按钮 |
| 作战准备 | 显示关卡名、推荐等级、理智消耗、右上角「开始行动」 |
| 战斗中 | 顶部有生命/费用/波次，底部是干员栏，右下角暂停 |
| 结算 | 大字「作战结束」/「行动失败」，有奖励列表 |
| 弹窗 | 居中对话框，通常有确定/取消 |

5. 报状态时写清楚：**哪一屏 + 关键数值**（理智、哪一关、费用、剩余敌人）。

## 注意

- MAA 抓的是桌面副本：游戏被别的窗口完全挡住时，会拍到挡住它的窗口 → 先切前台再看。
- 不确定界面就用 `game_find` 找关键文字确认，别猜。
