# 看游戏界面

用来看清楚游戏现在是什么状态。**这个技能不点击**，只负责读屏。

## 步骤

1. `cua_windows` 找到明日方舟窗口（标题通常是 "明日方舟" / "Arknights"），记下它的句柄/标题。
2. `cua_focus` 切到游戏窗口（被别的窗口挡住时截图会缺内容）。
3. `cua_screenshot` 拿一张最新截图；需要看清小字/小图标时用 `cua_zoom` 放大对应区域。
4. 按下面的特征判断在哪个界面，再去加载对应技能：

| 界面 | 特征 |
| --- | --- |
| 主界面 | 底部一排功能按钮（终端/干员/采购/档案…），右上角有理智 |
| 终端 | 关卡列表，分主线/活动/资源，右侧有「作战」按钮 |
| 作战准备 | 显示关卡名、推荐等级、理智消耗、右上角「开始行动」 |
| 战斗中 | 顶部有生命/费用/波次，底部是干员栏，右下角暂停 |
| 结算 | 大字「作战结束」/「行动失败」，有奖励列表 |
| 弹窗 | 居中对话框，通常有确定/取消 |

5. 报状态时写清楚：**哪一屏 + 关键数值**（理智、哪一关、费用、剩余敌人）。

## 注意

- 截图是桌面副本，游戏被完全遮挡时看到的可能是别的窗口，先切前台。
- 不确定界面就放大看文字，别猜。
