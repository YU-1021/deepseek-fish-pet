# 布阵与技能

作战准备和战斗中的操作规则。核心：**一次只放一个干员，放完立刻截图看效果。**

## 作战准备

1. 确认编队：读底部干员头像，报给主人「这队有谁、先锋/近卫/狙击/术师/医疗/重装/辅助/特种是否齐」。
2. 主人指定了编队就照配；没指定就先问「这次想用哪队/什么打法」。
3. 点「开始行动」进入战斗（如果 `进关卡` 还没确认过理智，这里再确认一次）。

## 战斗中

- 顶部读：费用、生命值、波次、是否暂停。
- 干员栏：头像亮 = 可部署（费用够、冷却好）；灰 = 费用不够或冷却中。
- 部署：选干员 → 拖到目标格子 → 选朝向（默认朝敌人来的方向，不确定就问）→ 松手。
- 撤退：点干员 → 撤退按钮。
- 开技能：点干员头像 → 技能图标；**自动开启**的干员不用手动点。
- 暂停：右下角暂停键，用于慢慢看局面。

## 基本判断

1. **先先锋再输出**：费用不够时先下先锋回费。
2. **重装挡人、输出清怪、医疗奶重装**；高台位优先放狙击/术师。
3. 费用留 10–15 应急，别一键花光。
4. 怪多/血线危险时先开技能再撤人。
5. 打不过（生命掉到 1–2）时先问主人要不要重开，不要硬打。

## 每次操作后

截图看：费用变了吗？干员放上去了吗？敌人被挡住了吗？没变化就换做法，别原地重复点。
