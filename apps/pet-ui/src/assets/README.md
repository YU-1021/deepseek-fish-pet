# Pet artwork

`fish-idle.webm` comes from the user's local `dsh-pet` installation:

`F:\DSH\.dsh\profiles\desktop\node_modules\dsh-pet\assets\webm\待机呼吸休闲.webm`

It is a transparent idle animation used in the floating pet window and chat header. The package README says its artwork is non-commercial and public derivatives should credit the project: [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet).

`click-duck.wav` comes from the same package's `assets/sound/click-duck.wav` and is played at half volume after a confirmed single click on the pet.
