## 待办（按优先级）

- [ ] **A. 智能审批门 UI（新，后端本轮升级）**
  - 后端把 hooks 升级成「模型判断风险 + 人只确认高风险」：`hooks.mode = smart` 时，低/中风险自动放行，高风险才弹审批；事件新增 `hooks.assessed {kind,name,risk,reason,cached,fallback}`。
  - 审批气泡要展示：风险等级徽标（low/medium/high）、模型给的原因、操作名与参数摘要、来源会话、倒计时、允许/拒绝/记住本次。
  - 设置页加「审批门」区：模式切换（rules/smart）、approvalEnabled、超时秒数、风险模型开关；规则列表里内置规则标只读。
  - `approval.list` 待答列表要有入口（红点 + 数量），点开逐条回答。
  - 新方法：`hooks.assess {kind,name,args?}` 可用于"预览风险"（只读展示，不影响真实调用）。
- [ ] **B. 静默活动（后端已就绪：`presence.*`）**
  - 后端已上线静默活动：默认每 45 分钟最多一次、用户闲置 10 分钟才动、夜间 23:00–07:00 安静、每天最多 12 次；**只广播事件、不聊天不朗读不调模型**。规格见任务书 §8.14。
  - 订阅 `presence.activity {id, kind, label, at, quiet}`：按 `kind` 播轻量小动作/表情（groom/stretch/window/nap/tidy/idle），**不弹气泡、不发声、不进聊天记录**；`quiet=true` 时只许动画。
  - 设置页「静默活动」分组展示 `presence.status`（开关/间隔/闲置门槛/每日上限/夜间时段），放一个「现在来一个」按钮调 `presence.run_once`。
  - 用户正在聊天/拖拽时推迟动作；不要轮询 `presence.status`、不要为动画调 `chat.send`。
- [ ] **C. 语音/朗读 UI（M5）**：设置页 voice 段；每条消息朗读按钮；停止按钮；`durationMs` 做口型；`voice.speech` 事件；data URL 播放需 Electron 自动播放解锁。
- [ ] **D. ASR/唤醒词 UI（M6）**：麦克风 16k PCM16 + AudioWorklet 采集；`asr.listen.start/feed/stop`；唤醒词指示；模型下载进度（`asr.download`）；autoChat 只读展示；隐私文案。
- [ ] **E. 提醒 UI（M8）**：列表、三种新建方式、到点 toast + 稍后按钮、合并补报、`reminder.*` 事件刷新。
