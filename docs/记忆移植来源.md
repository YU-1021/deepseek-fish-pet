# 工作区记忆 —— 移植来源与改造说明

petd 的「工作区记忆」是照 Coo（Coopanion 的 Cortico Cormini bot）的形状实现的。这份文档记录**哪些是移植、哪些是自写、许可证边界**，方便以后升级/回看。

## 一、上游

| 上游 | 位置 | 许可证 | 用到的部分 |
| --- | --- | --- | --- |
| Cortico `bots/cormini` | `Coopanion/vendor/cortico/bots/cormini/persona/`，vendor commit `8362383` | MIT | `memory.ts`（工作区读写/路径护栏/glob/grep）、`workspaceGit.ts`（Git 包装）、`workspaceTools.ts`（工具形状）、`persona.ts`（前缀装配、MEMORY_NOTE、折叠、压力/交接提示）、`handoffNote.ts`（交接笔记的预算/折叠**形状参考**，代码未移植，见 `petd/src/chat/handoff.ts`） |
| Coopanion（AGPL-3.0-or-later） | `Coopanion/core/persona.ts`、`core/companion.ts` | **AGPL，不复制代码** | 只参考了「5 处定制」的形状：PARTNER 全文进前缀、MEMORY_NOTE 换成桌宠版、写即 commit、启动快照 tag、折叠目录加 archive/ |

| 文件 | 对应上游 | 改造点 |
| --- | --- | --- |

| `apps/petd/src/memory/prefix.ts` | `persona.ts` 的前缀/折叠逻辑 | **自写**：`SEED_FILES`/`MEMORY_NOTE` 文案、`buildWorkspaceListing` 折叠规则、`buildChatSystemPrompt` 四段拼装、PARTNER 截断 |

| `apps/petd/src/chat/handoff.ts` | `handoffNote.ts`（形状参考） | **自写机械版**：token 粗估、`handoffs/<stamp>.md`、单条 600 上限/预算递减/折叠计数；没有移植其 LLM 渲染代码，也不做「更早/最近分段投递」 |
| `apps/petd/scripts/memory-smoke.mjs` | — | 自写：44 项端到端断言（含重启后仍在、常驻保护、路径逃逸） |
| `apps/petd/scripts/chat-memory-smoke.mjs`、`chat-handoff-smoke.mjs` | — | 自写：真 LLM 的聊天记忆（21 项）与上下文交接（26 项）端到端断言 |

## 三、明确没移植（后续需要再说）

- `blobs/` 附件存储与 `save_blob` 工具。
- `workspaceTools.ts` 的完整 agent 工具循环（petd 的 `ChatService.send` 已实现「模型调 9 个记忆工具」的循环，但不是 Cormini 那种通用 agent loop）。
- `handoffNote.ts` 的 LLM 渲染/分段投递：petd 目前是机械摘录（`chat/handoff.ts`），需要更聪明的摘要时再评估。
- Memory WebUI 页（那是 Cormini 的 WebUI 声明）：pet-ui 以后要走 `memory.*` 自己渲染。

## 四、许可证

- petd 仓库本身是私有仓库；Cormini 为 MIT，移植/改写合法，本文件即 provenance 记录。
- Coopanion 的 AGPL 代码没有复制进 petd；如以后要复用其具体实现，先按《cortico-移植规程》走许可证评估，或联系上游另行授权。
