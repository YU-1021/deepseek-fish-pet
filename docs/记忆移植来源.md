# 工作区记忆 —— 移植来源与改造说明

petd 的「工作区记忆」是照 Coo（Coopanion 的 Cortico Cormini bot）的形状实现的。这份文档记录**哪些是移植、哪些是自写、许可证边界**，方便以后升级/回看。

## 一、上游

| 上游 | 位置 | 许可证 | 用到的部分 |
| --- | --- | --- | --- |
| Cortico `bots/cormini` | `Coopanion/vendor/cortico/bots/cormini/persona/`，vendor commit `8362383` | MIT | `memory.ts`（工作区读写/路径护栏/glob/grep）、`workspaceGit.ts`（Git 包装）、`workspaceTools.ts`（工具形状）、`persona.ts`（前缀装配、MEMORY_NOTE、折叠、压力/交接提示）、`handoffNote.ts`（交接笔记预算折叠，**尚未移植**） |
| Coopanion（AGPL-3.0-or-later） | `Coopanion/core/persona.ts`、`core/companion.ts` | **AGPL，不复制代码** | 只参考了「5 处定制」的形状：PARTNER 全文进前缀、MEMORY_NOTE 换成桌宠版、写即 commit、启动快照 tag、折叠目录加 archive/ |

| 文件 | 对应上游 | 改造点 |

## 三、明确没移植（后续需要再说）

- `handoffNote.ts` 的上下文交接笔记：petd 还没有「上下文压缩/交接」流程，等聊天历史真的撑不住再接。
- `blobs/` 附件存储与 `save_blob` 工具。
- `workspaceTools.ts` 的 agent 工具循环（写/改/删/移动的模型可调用工具）：petd 目前由 `memory.*` 方法给 UI/上层用，等 agent 循环落地再接。
- Memory WebUI 页（那是 Cormini 的 WebUI 声明）：pet-ui 以后要走 `memory.*` 自己渲染。

## 四、许可证

- petd 仓库本身是私有仓库；Cormini 为 MIT，移植/改写合法，本文件即 provenance 记录。
- Coopanion 的 AGPL 代码没有复制进 petd；如以后要复用其具体实现，先按《cortico-移植规程》走许可证评估，或联系上游另行授权。
